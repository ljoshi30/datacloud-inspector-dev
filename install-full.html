Data 360 Inspector

See the API names, formulas, and logic that Data Cloud hides behind friendly labels — and copy or export any of it in one click. Data 360 Inspector reveals and copies API names across Data Cloud, and exports field lists and query results to CSV, Sheets, or Excel. Read-only, zero setup.

❓How to install & use
1. Show your bookmarks bar — ⌘⇧B (Mac) / Ctrl⇧B (Windows).
2. Drag the Data 360 Inspector button above onto the bookmarks bar. No install, no permissions.
3. On any Data Cloud / Data 360 page, click the bookmark — a purple circle button appears bottom-right; click it for the menu.
4. Click the bookmark again anytime to remove the tool. It never overlaps the Salesforce nav.

🔁DLO → DMO Mapping CanvasHoverPinExport

The gap: the canvas shows only field labels, and labels repeat — several fields on a DLO or DMO can read the same. So while you’re mapping, you can’t be sure which field you actually picked. The API name is unique and tells you exactly — but the canvas never shows it.

  • Hover any field to see its API name on both sides of the mapping — source (DLO) and target (DMO) — so you can confirm you mapped the right one. Press C to copy the one under your cursor.
  • Pin shows every API name on the canvas at once, so you can scan the whole mapping for the exact fields without hovering each one. Click any pinned name to copy it.
  • Export the full mapping as a table — source field → target field with both API names — to Google Sheets or CSV. Filter to one DMO first if you want.
When the same label exists on both a DLO and a DMO, the tooltip marks which side it read — so even with duplicate labels you always see the correct field’s API name.
🌐Data Stream & DLOExport Fields

The gap: to document a Data Stream or Data Lake Object’s schema today you read the Fields table and copy it one row at a time.

This exports the whole field list in one click — each row with its API name, label, data type, status, and key qualifier (primary key, event time, …). Straight to Google Sheets or CSV.

🗂DMO DetailExport Fields

The gap: a Data Model Object’s fields and relationships live on separate tabs, with no way to take them with you.

This exports both in one click, to Google Sheets or Excel (XLS):

  • Fields — API name, data type, whether the field is mapped, and its key qualifier.
  • Relationships — every object this DMO joins to, and the fields that join them.
🕸️Data GraphHoverFiltersCopy

The gap: the Data Graph builder shows only labels for the objects and fields you add — and labels repeat. So as you build, you can’t be sure which exact field you selected, or which one a filter is on. The unique API name tells you — but it’s nowhere on screen. Turn on API names from the ◎ button (bottom-right).

  • Objects & fields — the API name appears under each object on the left and each field on the right, refreshing as you click between objects.
  • Filters tab — the field chosen in each Sort and Condition dropdown gets its API name too.
  • Click any API name to copy it; every field also shows it on hover.
When two fields share a label, the Filters tab reads the exact selected field’s API from the page — never a guess — so you always get the one that was actually picked.
ƒFormula fields (Data Stream)HoverCopy

The gap: a Data Stream’s Fields table marks formula fields with just a checkmark in the Formula column — the actual expression is invisible unless you export. Turn on Show formulas from the launcher.

  • Hover the checkmark in the Formula column — a popover shows the full expression (scrollable if long) with a Copy button.

🔑Identity ResolutionAPI NamesCopy

The gap: the Identity Resolution ruleset shows each DMO section and its reconciliation fields by friendly label only (Account Multiline, Birth Date, First Name…) — not the API names you need for queries and integrations. Turn on API names from the ◎ button.

📊Data ExplorerColumnsDistinct valuesExport CSV

The gap: Data Explorer shows only ~10 columns at a time and a small slice of rows — hard to see or take the whole picture.

  • Columns — choose exactly which fields to show (well past the 10-column limit), reorder them, and save the set for next time; then view all their data in one table.
  • Sort, multi-filter, and a live row count on the results, plus Edit SQL to tweak the underlying query.
  • Distinct values (Σ) — hover a column header, click Σ, and get every distinct value in that column with its row count, each with Copy (plus Copy IN (…) for all of them). The fast way to grab a value for a WHERE clause instead of querying records to find it. Computed from the loaded rows — instant, no credits.
  • Export CSV — download the rows, fetched in batches up to 500,000, cancellable partway.
Saved column choices stay in your own browser (per org, cleared after 90 days). Nothing is written back to Salesforce.
🔎Query EditorCountFetch & ExportExport ALLHelpful QueriesViewDownload

The gap: the Query Editor shows at most 1,000 rows on screen and has no clean way to save a full result to a file. This adds a small toolbar (round button, bottom-left). Select some SQL to run just that; otherwise it runs the whole editor.

What each button does:

  • # Count The exact row count a query returns, without downloading any data — one quick call. Works with GROUP BY and JOINs.
  • ▶ Fetch & Export Fetches the rows (in batches, so it passes the 1,000-row screen limit) and saves a CSV. With no LIMIT it stops at 50,000 rows and tells you there were more; add a LIMIT to go up to 500,000. Bigger than that → Export ALL.
  • ⤓ Export ALL The entire result to CSV, no row cap. You choose the file first, then rows stream straight to disk as they’re fetched — so a huge table never exhausts browser memory. Cancel anytime with a live progress count; close the panel and it keeps running, reopen to see progress.
  • 🔧 Helpful Queries Writes common checks for you from a couple of dropdowns — duplicates, nulls/blanks, stale records, orphaned keys, a date range, and the distinct values of a column (handy for grabbing a value to put in a WHERE clause). No SQL needed.
  • 👁 View Results Shows fetched rows in a table on the page (up to 2,000) so you can glance without opening a file. Click any cell to copy it. No extra query.
  • ⬇ Download CSV Saves rows you’ve already fetched. No new query — so no extra credits.
Credits: Data Cloud bills by rows processed (scanned), not returned — a heavy JOIN or GROUP BY can cost more than its result size suggests. The toolbar shows your org’s rate and an estimate, and reuses results: re-running the same query or re-downloading a fetched file is free, and re-running an Export ALL warns you first so you don’t pay twice.Big results: a CSV holds any number of rows, but Excel caps at ~1,048,576 rows and Google Sheets at ~10 million cells. Past that, export in slices (e.g. by date range) — the tool warns you before you’d silently lose data.
🏁SegmentExport RulesAPI NamesContainer Path

The gap: the segment builder shows rules by friendly label — but the same label can mean different fields on different objects, so you can’t be sure which field a rule actually targets. The API name makes it exact — and there’s no way to take the rules with you.

  • Hover any attribute or rule for its object and field API name; press C to copy.
  • Export every condition — Include, Exclude, Rank & Limit — with the full AND/OR logic, nested segments, and sub-filters intact, plus object and field API-name columns. Colored Excel or Copy for Sheets for review, or a flat CSV built for scripts/automation (every row fully filled — tab, group #, join, condition #, API names — no merged cells).
  • Container Path shows which related record a rule actually points at, read straight from the open edit panel.
Everything is read from what’s on screen — the Container Path is never reconstructed or guessed; if Data Cloud doesn’t show it, neither does the tool.
🎯ActivationAPI NamesExport

The gap: same label-only problem as Segment, in the activation wizard where you choose attributes.

  • Hover any attribute in the main table or in “Add Additional Attributes” for its object and field API name.
  • Export the activation’s included attributes with their object and field API names in one click.
API-name hints live on the wizard (where attributes exist). A finished activation’s read-only page has no attributes to label, so it offers Export only.
📥Data Space FiltersExcelSheets

The gap: a Data Space can filter which records of an object (DLO) belong to it — grouped conditions joined by AND/OR, just like a segment. Salesforce lets you build that filter but gives you no way to take it with you to document or review.

  • Open an object’s Edit Filters, then click Export Filters — you see the whole filter as a colored, grouped grid (like the Segment export): one row per condition with its object, field label, field API name, operator, and value.
  • The grouping is preserved and color-coded — each group is a tinted band (blue for AND groups, purple for OR) with its within-group and between-group logic shown — plus a plain-English summary like (A = true AND B IS EMPTY) OR (C = x).
  • Download Excel (same colored layout, bold header) or Copy for Sheets to paste the grid straight into Google Sheets.
The operator within each group comes straight from the filter’s data. The operator between groups is read from the on-screen AND/OR bar; if the filter isn’t open so that bar is visible, the export marks it blank rather than guessing.
⚙️Data TransformPlain-English summary

The gap: a Data Transform’s definition is dense — understanding what it does means reading its raw node graph or SQL.

This reads the transform and writes a plain-English, step-by-step summary: the sources it reads, the filters it applies, any formulas and joins, the outputs it writes, and which fields are kept, dropped, or renamed. Download it as an HTML file you can print to PDF.

🗺️Data Model (ERD)Diagram

The gap: Data Cloud has no way to export your data model as a diagram you can share or document.

  • Generates a copyable Mermaid ERD you can paste into Lucidchart, draw.io, GitHub, or any Markdown doc.
  • Includes a cardinality legend (one-to-many, etc.) so relationships read clearly.
  • Searchable entity cards — look up any object and see everything it connects to.
📂Open in New Tab (lists & nav)⧉

The gap: most Data Cloud list rows and menu items aren’t real links — the name runs a script, so right-click → “Open in new tab” does nothing and you end up duplicating the whole tab.

  • Hover a row in any object list (Data Streams, DLOs, DMOs, Calculated Insights, Segments, Activations, Data Graphs, Identity Resolution, …) and a ⧉ button opens that exact record in a new tab.
  • Hover any left-menu or top-bar item for the same ⧉ — covers every destination, including newer ones.
It reads each row’s own record id and ignores lookup columns (e.g. a “Data Space” cell), so it always opens the row’s record — never a related one. Works as you navigate, no re-clicking needed.

Panels are draggable & resizable. The × on a menu just closes it; click the bookmark again to remove the tool completely.

🔒Privacy & safety
  • Runs entirely in your browser — no external servers, no third-party services.
  • Uses Salesforce’s own APIs (same-origin). No data leaves your browser or your org.
  • Nothing is stored permanently — the tool disappears on page reload. Column selections use localStorage (per-org, 90-day TTL).
  • Read-only: it never creates, modifies, or deletes any Salesforce data.
  • No installation required — no package, no Connected App, no admin approval.
  • Anonymous usage counts: this install page uses privacy-first analytics (no cookies), and the tool may report an anonymous usage count — a random browser id, the tool version, and which type of page it ran on — so the team can measure adoption. It never includes any record, field, personal, or org data.
