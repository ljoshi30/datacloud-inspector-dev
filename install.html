❓How to install & use
1. Show your bookmarks bar — ⌘⇧B (Mac) / Ctrl⇧B (Windows).
2. Drag the Data 360 Inspector button above onto the bookmarks bar. No install, no permissions.
3. On any Data Cloud / Data 360 page, click the bookmark — a purple circle button appears bottom-right; click it for the menu.
4. Click the bookmark again anytime to remove the tool. It never overlaps the Salesforce nav.

🔁DLO → DMO Mapping CanvasAPI TooltipPin API namesExport

The mapping canvas normally shows only field labels — not the API names you actually need when building queries, transforms, or integrations. This fills that gap.

  • API Tooltip — hover a field to see its API name on both the source (DLO) and target (DMO) side; press C to copy. When on, the button shows a green “• ON” so you know it’s live.
  • Pin API names — show every API name on the canvas at once, so you can read the whole mapping without hovering. Click any pinned name to copy it (it flashes “✓ Copied”).
  • Export — download the full mapping table (source field → target field, with both API names) to Google Sheets or CSV. You can filter to a single DMO first.
Good to know: if the same label is used on both a DLO and a DMO, the tooltip marks which side it read so you’re never shown the wrong API name.
🌐Data Stream & DLOExport Fields

On a Data Stream or Data Lake Object page, export the complete field list in one click — no copy-pasting row by row.

Each row includes the API name, label, data type, status, and key qualifier (primary key / event time / etc.). Copy it straight into Google Sheets, or download as a CSV.

🗂DMO DetailExport Fields

On a Data Model Object detail page, grab both tabs of information:

  • Fields — API name, data type, whether the field is mapped, and its key qualifier.
  • Relationships — the objects this DMO is related to and the fields that join them.

Copy it into Google Sheets, or download as an Excel (XLS) file.

Modals are draggable & resizable. The × on a menu just closes it; to remove the tool entirely, click the bookmark again.

🔒Privacy & safety
  • Runs entirely in your browser — no external servers, no third-party services.
  • Uses Salesforce’s own APIs (same-origin). No data leaves your browser or your org.
  • Nothing is stored permanently — the tool disappears on page reload. Column selections use localStorage (per-org, 90-day TTL).
  • Read-only: it never creates, modifies, or deletes any Salesforce data.
  • No installation required — no package, no Connected App, no admin approval.
