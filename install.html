Data 360 Inspector

Floating toolkit for Salesforce Data Cloud — reveals API names on the DLO→DMO mapping canvas and exports Data Stream, DLO, and DMO fields to Sheets, CSV, or Excel.

No install · works in any browser

Add the bookmarklet

  1. Show your bookmarks bar: ⌘⇧B on Mac  /  Ctrl⇧B on Windows.
  2. Drag this button to your bookmarks bar:   Data 360 Inspector
  3. Open any Data Cloud / Data 360 page in Salesforce and click the bookmark. A blue circle with a magnifying-glass icon appears in the bottom-right corner — click it to open the action menu.
  4. Click the bookmark again at any time to remove the tool.
The launcher sits in the bottom-right corner and never overlaps the Salesforce navigation. Click the 🔍 button to expand the menu; click outside or click it again to collapse.

Features by page

🔁 DLO → DMO Mapping canvas

  • API Tooltip — hover any field to see its API name in a tooltip; click to copy to clipboard
  • Pin API names — pins all API names directly on the canvas at once; click Unpin names to clear
  • Export — full DLO→DMO mapping table filterable by DMO · Copy for Sheets or Download CSV

🌐 Data Stream & DLO detail pages

  • Export Fields — all fields with API name, label, data type, status, and key qualifier · Copy for Sheets or Download CSV

🌐 DMO detail pages

  • Export Fields — Fields tab (API name, type, mapped status, key qualifier) and Relationships tab (related objects and join fields) · Copy for Sheets or Download XLS

All modals are draggable (grab the header) and resizable (drag the bottom-right corner).

Privacy & safety

  • Runs entirely in your browser tab using data the page has already loaded.
  • No API calls, no network requests, no data sent anywhere.
  • Nothing is stored — the tool disappears when you close or reload the tab.
  • Read-only: it never modifies your Salesforce data.
