🔎 DOM Probe  ← drag this to your bookmarks bar

  1. Drag the button above to your bookmarks bar.
  2. Open an Activation page (the edit view is best — the /view page may show fewer fields).
  3. Make sure the attributes / contact points are on screen.
  4. Click the DOM Probe bookmark → it copies a snapshot to your clipboard.
  5. Paste it back in chat.
What it captures (read-only): the attribute inventory a DOM-only export could use — the activation datatable .data[] (name, object, output name), the summary .includedAttributes[] (field API, object API), drag-item details, plus a sniff of membership / segment / channel / target props and each element's full LWC prop-name list (so we see what else is available). No raw HTML; never changes the page.
