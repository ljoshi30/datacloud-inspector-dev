Data 360 Inspector

A browser-based toolkit for Salesforce Data Cloud. Zero setup. Read-only. Works on any org.

What It Does

Segment Segment Rule Export

WhatReads all segment conditions (Include, Exclude, Rank & Limit) from the builder canvas and exports them
OutputCopy to Google Sheets or download as formatted HTML/Excel
Gap solvedNo native way to export segment logic for documentation, audit, or sharing with non-SF users
Time saved15-20 min manual documentation per segment → 1 click

Explorer Data Explorer

WhatView ALL columns, filter, sort, count records, and export any DLO/DMO data as CSV
Key features
  • Breaks SF's 10-column display limit — view all 40+ fields at once
  • Save/restore column selections (persists across sessions)
  • Multi-condition filter with real-time COUNT
  • Export All — download entire object (up to 500K rows) as CSV
  • Edit SQL — inline query editor with editable WHERE/LIMIT
  • Sort any column, hide empty columns
Gap solvedSF Data Explorer limits to 10 columns, 100 rows, no export, no inline filter
Time savedData validation: 30+ min (write SQL, use API) → 30 seconds (filter + count + download)

Query Query Editor Export

WhatRun any SQL query and export full results as CSV — bypasses SF's 1,000-row UI limit
Key features
  • Paginated export (up to 500K rows) with progress + cancel
  • Highlight SQL → click Run & Export → CSV downloads
  • Actionable error messages
Gap solvedSF Query Editor limits to 1,000 rows, has NO download/export option (no CSV, no Excel)
Time savedExporting query results: build API integration (hours) → 1 click

Transform Data Transform Summary

WhatAuto-reads the transform definition and generates a plain-English summary
Key features
  • Branch-by-branch breakdown in readable language
  • Shows: which fields are kept/dropped/renamed
  • Download as styled HTML (printable as PDF)
  • AI-powered explanation (optional)
Gap solvedUnderstanding a 20+ node transform requires clicking into each node one by one. No native documentation feature.
Time savedDocumenting a transform: 30-60 min → instant. KT for new member: 1-hour walkthrough → share the summary

Key Differentiators

Zero setup — drag a bookmarklet, works instantly. No Connected App, no API keys, no admin approval.
Read-only — never modifies any Salesforce data. Safe for production.
Works on any org — no package install, no metadata deployment.
Breaks native limits — 10-column cap, 100-row cap (Explorer) / 1,000-row cap (Query Editor), no-export limitation — all bypassed.
Instant documentation — transforms, segments, and data exports generated automatically.
